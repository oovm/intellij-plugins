# WIT IDL

[IntelliJ Platform](https://plugins.jetbrains.com/plugin/24001-wit-idl) plugin for the
[WebAssembly Interface Type (WIT)](https://github.com/WebAssembly/component-model/blob/main/design/mvp/WIT.md)
language (`.wit` and legacy `.witx`).

## Features (MVP)

- Lexer and parser for package / interface / world declarations
- Syntax highlighting
- Brace matching and `//` / `/* */` comments
